## Site layout (`site/`), restructured and published 2026-11-04

No build step: plain HTML, CSS and JS. Five pages, same nav and footer on each:
- `index.html` "Check your state": night map + search. The state panel (`app.js`) shows the rule, alert days, summer 2024 shut-offs (`eia.js`), live-bill notes (`NEWS` object in `app.js`, as of Oct 2026), and a per-state "what to ask for". Then the sortable table.
- `findings.html` "Why it matters": scale (EIA), cases (Pullman, Korman), gaps, CA/IL before-after, timeline of wins, "what critics say".
- `act.html` "Take action": the advocacy guide. 5 steps, checklist (localStorage), EPIC script, templates (from `templates.md`), live fights MA/PA/FL/VT, can students do this.
- `about.html` "About us": what we ask for, SDGs, team (`team.js`, renders into `#teamlist`), start a chapter, other groups.
- `method.html` "How we know": method, limits, mistakes caught, prior work, sources.
- `team.html` is now only a redirect to `about.html#team`.
- `eia.js` is generated by `uv run --with pdfplumber python eia_check.py`. `data.js` by `build.py`. Don't edit either by hand.
- Design: Newsreader headings + Atkinson Hyperlegible body (19px), warm paper palette, rust accent. Motion: map states flicker off like a power cut, highlighter marks draw once, table row warms on selection. All off under reduced-motion.
- Internal planning (HCB, legal setup, 90-day plan, marketing) is deliberately NOT on the public site.
- Live-bill notes need re-checking whenever MA H5175 or PA SB 154/HB 2333 move.

## Deliberate decisions (don't "fix" these)

- **ZIP lookup falls back to ZIP3,** so a made-up ZIP like `10000` still matches a state. Strict matching would reject real PO-box ZIPs like `33101`. Codex flagged this, and the fallback was kept on purpose.
- **Delaware is shown as 76%** (computed from unrounded data). Recomputing from rounded numbers gives 77%.
- The site says "we" but doesn't claim nonprofit status. Don't claim it until fiscal sponsorship (Hack Club HCB, see `nonprofit-playbook.md`) is done.
- "Heat Shut-off Check" is a working name. Change it if the organization picks another.

## Gotchas when working on this

- On this Mac, `/usr/bin/python3` has CA certificates. The python.org build fails HTTPS with CERTIFICATE_VERIFY_FAILED.
- To test locally: `cd site && python3 -m http.server`.
- To regenerate data: `/usr/bin/python3 build.py` (the weather archive is cached under `raw/`; a cold run is slow).
